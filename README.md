Descripción
En este laboratorio el estudiante se familiarizará con el entorno de desarrollo PlatformIO y
la programación del microcontrolador ESP32 utilizando el framework de Arduino. El
objetivo es desarrollar una aplicación que permita configurar y controlar los pines GPIO
como entradas y salidas digitales mediante la implementación de un contador de 4 bits.
El sistema deberá operar en dos modos de funcionamiento: un contador de décadas y un
contador binario, seleccionables mediante un botón. Además, se implementarán botones
para incrementar y decrementar el contador, aplicando técnicas de anti-rebote y
configuraciones de entrada utilizando resistencias pull-up y pull-down.

Objetivos
1. Configurar y utilizar los pines GPIO del ESP32 como entradas y salidas digitales para
implementar un sistema interactivo.
2. Implementar una aplicación en lenguaje C++ que utilice la lectura de entradas
digitales para controlar un contador de 4 bits con diferentes modos de operación.
3. Diseñar un sistema que integre diferentes configuraciones de entradas digitales
(pull-up, pull-down interno y pull-down o pull-up externo), aplicando técnicas de
anti-rebote para garantizar un funcionamiento confiable.
